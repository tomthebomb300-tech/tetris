## Tetris Game
A classic Tetris game developed in C using the Windows API (WinAPI) for window management and input handling, and OpenGL for 2D graphics rendering. Features include tetromino movement and rotation, collision detection, line clearing, score tracking, and a HUD displaying the score and upcoming piece. The project explores low-level programming concepts, memory management, bitwise operations, and real-time game development.

## Controls
- "Up Arrow" turns your piece
- "Down Arrow" increases piece drop speed
- "Left Arrow" move piece left
- "Right Arrow" move piece right
- "ESC" will pause/resume play
- "ENTER" after "GAME OVER" screen appears will restart the game.
